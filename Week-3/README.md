# Week 3 — Machine Learning Model Development & Evaluation Plan

This folder contains the Week 3 work for the Virtual Data Science Explorer Internship at YuvaIntern.

## Project

**Student Academic Performance Prediction and Analysis Using Python**

## Objective

The objective of Week 3 is to design a structured machine learning development and evaluation plan using Python.

The plan covers:

* Problem definition
* Data preprocessing
* Feature engineering
* Feature selection
* Model selection
* Model training
* Hyperparameter tuning
* Cross-validation
* Model evaluation
* Error analysis
* Model interpretation
* Conceptual deployment and maintenance

## Proposed Models

* Logistic Regression
* Decision Tree
* Random Forest
* Dummy/Majority Classifier as a baseline

## Evaluation Metrics

* Accuracy
* Precision
* Recall
* F1-score
* ROC-AUC where appropriate
* Confusion Matrix
